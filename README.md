# MY MONEY

개인 가계부 · 자산 관리 앱 (아이폰 홈 화면용 웹 앱)

- 기록은 **각자의 아이폰 안에만** 저장돼요. 이 저장소에는 어떤 기록도 올라가지 않아요.
- 인터넷이 없어도 열려요. 주식 시세·환율만 인터넷이 필요해요.

## 아이폰에 설치하기
1. Safari에서 이 앱 주소를 열어요
2. 공유 버튼(□↑)을 눌러요
3. **홈 화면에 추가**를 선택해요
4. **웹 앱으로 열기**를 켜고 **추가**를 눌러요
5. 홈 화면의 **MY MONEY** 아이콘으로 실행해요

## PC 기록 옮기기
PC 가계부에서 *백업 파일 저장* → 파일을 아이폰으로 보내기(카카오톡 나에게 보내기, AirDrop, iCloud Drive) →
앱의 **설정 → 백업 불러오기**에서 그 파일을 선택해요.
